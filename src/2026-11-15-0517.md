# The interface finally looks like the game

![Combat with the new interface](media/2026-11-15-0517/2026-11-15_0409_ui_dark_illumination.jpg "Dark illumination skin, combat. Playtest build.")

**In short**: the layout was fine, but the interface read like a debug menu. We kept every screen where it was and changed only its material.

### How we chose
- Two directions on the same three elements (a card, the boss frame, the card pick): a thin vector filigree, and a "dark illumination" with metal frames, name ribbons and set cost gems.
- We picked the illumination: more character, easier to recognise.

### What changed
- One material everywhere: bevelled metal on a faint vellum grain.
- Action and movement points take the full width under the health bar; only the number pulses when a card will spend it.
- Cards keep their pixel rarity border, with the rarity written small at the bottom.
