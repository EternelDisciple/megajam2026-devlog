# It ran fine on Linux. On Windows, nothing happened.

![The hub, as it should look in the Windows build](media/2026-11-15-1517/2026-11-15_1517_hub_windows_build.jpg "The hub in the fixed build, English version. Playtest build.")

**In short**: our first Windows test of the day showed nothing at all. No window, no error, no log.

### What went wrong
- Two settings were read from the command line before the engine had even started. The editor forgives that. A packaged game quits silently.
- Then the game started, but the Spirit was a white cone and the hub had no floor: some files were loaded by name and never packed.
- The end credits and the color grading were missing too.

### What we changed
- Every Windows build is now launched automatically before anyone sees it. If the engine does not start, the build is rejected.
- A check lists every asset the code asks for and compares it with what was packed.
