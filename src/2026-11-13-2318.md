# One look for every screen

![Eight screens, before and after the interface pass](media/2026-11-13-2318/2026-11-13_2152_ui_pass.jpg "Playtest build.")

**In short**: the interface had grown in three layers. We picked one direction and redid every screen with it.

### The direction
- Night tones, moonlight and lavender, ember kept for the one action that matters.
- Frames and edges in crisp pixel art, so the interface belongs to the same world as the game.
- Card rarity is read from the frame's material, and rare cards give off pixel smoke.

### What changed
- Combat, hub, dialogue, main menu, pause and options now share the same pieces.
- Text sizes went up for readability.
- No more full-screen flashes anywhere.
- Explanations only show when you ask for them.
