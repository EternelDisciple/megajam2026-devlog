Prepared before the jam

The jam rules say: start nothing before Nov 12, and declare every prompt, script or asset made before.
Everything below was made between Nov 8 and Nov 11, 2026, by me (EternelDisciple) with Claude Code.
None of it is the jam game: no game idea, no game code, no game art. Kits are reused as tools.

Knowledge and workflow

  • GameDevKB: my notes for game dev with an AI agent: Unreal 5.9 under Linux, Slate UI, VFX, audio, licences, AI image and 3D pipelines, playtest lessons.
  • Day 1 script (new_ue_project.sh): one command creates the Unreal 5.9 project (agent-ready template, MCP server, git, private repo) with every kit below plugged in. Rehearsed on Nov 11.
  • Editor control scripts: small Python wrappers to drive the Unreal editor through Epic's MCP server, plus OBS control to record clips.
  • uxcheck: checks game screenshots for colour-blindness issues, contrast, amount of on-screen text, and feedback coverage.
  • Fab licence list: my Fab library sorted by licence, to use only assets that allow commercial use.
  • DevlogKit: the generator and the automatic privacy check behind this site.

Unreal plugins (C++, no Blueprint graphs)

  • JuiceKit: game feel (shake, hitstop, springs, flashes) with accessibility switches.
  • OptionsKit: settings menu (video, audio, language, accessibility). Rewritten from the options menu of my previous game, with no dependency on it.
  • CardKit (3D) and CardKit2D: playing cards, hand, booster opening; the 2D version is pixel art with a CRT effect.
  • CaptureKit: frame-exact video and GIF capture (UI included), with game sounds remixed in.

Audio

  • SfxKit: procedural sound effects computed from parameters (no samples, no AI model).
  • MusicKit: local music loops and jingles with ACE-Step 1.5, plus a listening catalogue.
  • Song pipeline: local scripts to generate, sort and clean up a sung song.

Images and 3D (local models)

  • Pixel-art and sketch-style pipelines (PixelLab, CharaLab): pose-guided generation, palette and pixel-grid clean-up.
  • Consistency tools: scripts that measure whether a character and a style stay the same across images.
  • NightLoop: overnight generation, automatic pre-sorting, morning selection page, then LoRA training. Still being validated.
  • Experiments (throwaway): 3D character from a concept, auto-rig and retargeting; a small tactics test project.

Contributions

  • ue-linux-win64 (an open-source tool by Ezyrath): package Windows builds from Linux. My pull request adding Unreal 5.9 support was merged upstream on Nov 11.
